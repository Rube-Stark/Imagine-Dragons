# 🎵 Imagine Dragons — Fan Page Website

Este proyecto es una **fan page interactiva** dedicada a la banda **Imagine Dragons**, creada con el objetivo de practicar desarrollo web, diseño responsivo y organización de contenido multimedia en un entorno moderno y atractivo.

---

## 🌐 Descripción general

El sitio web está inspirado en el estilo visual y sonoro de Imagine Dragons, combinando colores intensos, animaciones suaves y secciones dinámicas.  
Incluye información sobre la banda, discografía, videos, galería de fotos y enlaces a sus redes oficiales.

El proyecto fue diseñado para ofrecer una **experiencia de usuario fluida**, con un enfoque **responsive** que se adapta a dispositivos móviles, tablets y escritorios.

---

## ✨ Características principales

- 🎸 **Sección “Banda”** — historia, integrantes y origen.  
- 💿 **Discografía interactiva** — álbumes con carátulas, años y lista de canciones destacadas.  
- 🎬 **Multimedia** — integración de videos y música (YouTube / Spotify).  
- 🖼️ **Galería visual** — imágenes con animaciones hover y efectos de luz.    
- 📱 **Diseño 100% responsivo** — compatible con todos los tamaños de pantalla.  

---
